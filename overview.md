NpcScript is an instruction-based Unity editor and runtime for dialogue, character actions and cinematic sequences. The release targets Unity 6.3. The sample content uses standard Unity modules and package-local materials.

1. [Create your first interaction]({{ '/getting-started/' | relative_url }})

4. [Dialogue]({{ '/dialogue/' | relative_url }}), [cutscenes]({{ '/cutscenes/' | relative_url }}) and [localization]({{ '/localization/' | relative_url }})
5. [Custom commands]({{ '/custom-commands/' | relative_url }}), [API reference]({{ '/api-reference/' | relative_url }}) and [runtime debugging]({{ '/runtime-debugging/' | relative_url }})
6. [Troubleshooting]({{ '/troubleshooting/' | relative_url }}), [release notes]({{ '/changelog/' | relative_url }}) and [third-party notices]({{ '/third-party-notices/' | relative_url }})

Open **Tools → NpcScript → Getting Started** for example scene shortcuts. In a fresh project, keep the standard Unity AI, Physics, Animation, Audio, Director, IMGUI and JSON Serialize modules enabled. Navigation commands use an existing NavMesh. The sample NavMeshes are baked and included.
