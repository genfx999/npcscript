# NpcScript product website

GitHub Pages publishes the root of the main branch at https://genfx999.github.io/npcscript/.

The Markdown pages mirror the customer guides for NpcScript 1.0.0. Keep their permalinks and front matter when updating them. GitHub Pages builds the Jekyll site directly from `main`.

Set `asset_store_url` and `demo_video_url` in `_config.yml` when the real listing and video are available. Set `support_email` and `support_issues_url` there after the publisher establishes those channels. Blank values leave the corresponding links off the site. To add a video to one gallery card, set its `video_url` in `_data/examples.yml`.

Use genuine Unity captures for gallery images. The editor image shows the shipped Beacon Dialogue program, and the gameplay captures show the included sample scenes.
