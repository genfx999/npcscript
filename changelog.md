## 1.0.0

- Initial standalone release preparation for Unity 6.3.
- Visual program editing, validation, instruction and block foldouts, stepping and active-line highlighting.
- Dialogue, commands, conditions, loops, expressions, nested programs and in/out parameters.
- Five guided demos and the original Beacon sample.
- Local user documentation, an opt-in examples window and sample C# integration code.
